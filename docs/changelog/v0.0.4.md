# Personal Research Workbench 0.0.4

Windows 10/11 x64 NSIS release. This release completes the in-process Pi Agent integration across provider configuration, research context, local Workbench actions and confirmed external-write requests.

## Highlights

- Provider-scoped API-key/OAuth configuration remains Main-owned and safeStorage-backed; credentials are never written to `models.json`, SQLite, prompts, ledger records or logs.
- Added controlled provider/model discovery and strict provider-qualified model selection for custom providers.
- Added Agent MCP access to literature, notes, Zotero read operations, schedules, non-secret Agent settings and local task/calendar/Todo actions.
- Added Zotero and Obsidian request/preview/confirmation boundaries with revision/fingerprint protection; external writes are not unattended.
- Added local Agent magic commands for provider/model/login/settings shortcuts without sending secrets to the model.
- Restricted Pi skill and extension loading to repository-owned or packaged application-owned resources; personal `~/.pi` and `~/.codex` resources are not read.
- Improved dark-theme contrast, native select rendering, responsive layouts and Agent/settings presentation.
- Added Quick Start and detailed Agent usage documentation.
