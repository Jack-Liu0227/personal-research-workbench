# Personal Research Workbench 0.0.3

Windows 10/11 x64 NSIS release. This release fixes packaged-app startup and
adds a user-confirmed in-app update flow while preserving the local-first data
model.

- Authenticode: unsigned (`NotSigned`)

## Highlights

- Packaged builds store SQLite, integration configuration and encrypted secrets
  in the per-user Windows AppData directory instead of the installation folder,
  avoiding startup crashes caused by Program Files write restrictions.
- On first launch after upgrading, legacy `data/` and `config/` folders next to
  the executable are copied into the user profile without overwriting files
  that already exist. The legacy source remains in place for recovery.
- Settings now provides check, download, progress and restart-to-install
  actions for GitHub Releases through `electron-updater`. Updates never replace
  the SQLite database, configuration or safeStorage-backed credentials.
- The Zotero page keeps the write-permission entry visible while capability
  probing, after failures, and for read-only connections. Clicking it retries a
  probe before requesting authorization so a stale capability state can recover.
- Shared renderer styling was refreshed with a Geist-first type stack, neutral
  surfaces, a single teal accent, clearer focus/loading/active states and
  responsive reduced-motion behavior.

publisher warning. Real Zotero authorization and clean-machine Windows
round-trip testing remain environment-dependent follow-up checks.
