# Personal Research Workbench 0.0.5

Windows 10/11 x64 NSIS release for the research intelligence, RSS and Feishu delivery slice, together with the current Agent/runtime and workspace-service changes in this release tree.

## Highlights

- Added Intel Daily configuration and overview surfaces for research intelligence workflows.
- Added RSS source, category, preview, refresh and item-query flows with database persistence and workspace-service orchestration.
- Added Main-owned Feishu app binding, OAuth handoff/status, test-message delivery and credential-boundary handling.
- Added daily intelligence and RSS delivery contracts, migrations, repositories, MCP/service dispatch and focused tests.
- Improved Agent/Core/Main/Preload integration, research settings, ledger grouping and Electron E2E coverage.
- Added the Agent LLM integration skill and implementation guidance without exposing credentials or personal provider configuration.

## Release safety

- External writes and real provider/OAuth/Feishu/Zotero/Obsidian round-trips remain environment-dependent and are not implied by this release.
- Authenticode signing and packaged-app page-by-page UI regression remain open unless separately evidenced below.
- The release is a normal increment after the published `v0.0.4`; no downgrade is involved.
