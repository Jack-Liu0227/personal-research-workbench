# Personal Research Workbench 0.0.6

Windows 10/11 x64 NSIS release. This is an increment after v0.0.5.

## Highlights

- Reworked the research shell using the research-workbench/web design reference: light/dark themes, derived accent colors, Provider cards and a three-column Agent workspace.
- All 16 settings sections use left-sidebar navigation, including compact-window drawer and keyboard support, not top tabs.
- Added persistent assistants, bounded read-only director teams, and atomic tool/skill enable-disable matrices enforced by Core and the Pi runtime.
- Added third-party Streamable HTTP MCP server management, explicit discovery, safeStorage Bearer credentials and separate, once-only human approval for remote tool calls.
- Added reviewed SQLite-backed instruction skill installation/editing; changed text revokes bindings until explicitly reauthorized. Skills cannot install or execute code.
- Added migrations 38/39 and restart persistence. Retired Python sidecar execution and excluded sidecars from the installer.
- Packaged metadata now uses the product-specific name `personal-research-workbench`, giving NSIS/updater a dedicated cache instead of the workspace npm scope cache. App ID, executable, product name and default user data remain unchanged; the old cache is not migrated or overwritten.

## Verification

- Typecheck and production build pass; resource tests 27/27, assistant/team tests 42/42 and Pi tests 57/57 pass.
- Real Electron UI regression passes: assistant/settings 33 workflows/136 screenshots, MCP/skills 6 workflows/18 screenshots, plus general application regression.
- Independent bounded local backend and UI review approves the tested scope. Loopback SDK fixtures are not real online Provider or remote-service acceptance.
- Actual installer identity and install/start/restart/reinstall/uninstall results are appended after execution, not inferred from compilation.

## Safety And Limits

- This installer is **unsigned (no Authenticode certificate)**. Windows may display a security warning.
- Remote MCP supports Streamable HTTP only, not stdio/command/env/arbitrary headers. Tools require explicit binding and separate approval; remote side effects cannot be rolled back by cancellation.
- Teams remain bounded and read-only. User skills are instruction text, not executable plugins. Python sidecar functionality is retired, not silently restored.
- Real online Provider/OAuth, external MCP/Zotero/Obsidian writes, previous-version installer upgrade, automatic update and clean-machine/OS-scale coverage are not implied. Same-version reinstall is not a cross-version upgrade.
- A long Agent model pill may truncate at 200% application zoom; tested resource save/approval controls remain reachable.
