## 安装

1. 运行安装包，选择安装目录（默认按用户安装，不写系统目录）。
2. 首次启动会在**安装目录**下创建本地数据（`data/workspace.sqlite3`、`config/`、`workbench/`），这是打包态的既定行为：默认以自身 exe 目录为可移植数据根。
3. 需要与安装目录隔离时，用显式参数启动：

   ```powershell
   research-workbench.exe --prw-user-data-dir="D:\path\to\profile"
   ```

安装包**没有代码签名**，Windows SmartScreen 会提示未知发布者；请用上面的 SHA-256 校验下载完整性。

## 本版包含

- **Zotero**
  - 文献检索页所有写入入口都常驻显示写入权限状态，可从「请求 Zotero 写入权限」→ Collection/项目分类 → 冻结 preview → 显式确认 → 逐条回执完成导入；失败条目可单独或批量重新预览导入。
  - Zotero 页面支持条目两侧删除：先用官方 Local API 合同（`DELETE <library>/items/<itemKey>` + `Zotero-Server-ID` + `If-Unmodified-Since-Version`）永久删除远端条目，只有远端返回成功或确认不存在后，才归档本地 Paper 投影并删除外部链接映射；远端冲突、无权限、无稳定 key 或网络失败时本地记录全部保留。
  - 本机 loopback 写入与删除都要求「始终允许」得到的持久 key；一次性 key、模式未知的 key 在任何请求发出前就被阻断，并给出可操作的说明。Zotero 9 缺少 `Zotero-Server-ID` 时权限按钮可见但禁用，并提示升级。
- **文献 skill**
  - 新增项目自有 `literature-matrix`、`literature-review-push` 两个指令技能：主题/时间范围/来源/字段模板驱动的文献矩阵与证据链综述，默认离线，`--online` 显式开启联网；输出交给 Artifact/Obsidian 投影，技能本身不写 Zotero/Obsidian，不读 `zotero.sqlite`、`.obsidian`、`.env` 或 `~/.pi`。
- **仪表盘与日历**
  - 仪表盘删除示意性卡片，Agent 收件箱只展示真实 Inbox 记录与每日推送账本的 join 结果；未匹配的行保留显示并标注真实原因，不伪造推送状态、规则名或 Obsidian 路径。
  - 每日推送作为**只读虚拟事件**接入日历：计划中的下一次运行显示为「已计划」，历史 occurrence 的完成/阻断/跳过/失败来自持久化账本；虚拟事件不可拖动、缩放、编辑或删除，点击进入对应定时任务或运行历史。
- **Agent 与自动化**
  - Agent 对话历史支持当前筛选范围的全选/半选/清除/逐条与批量删除，带 revision 校验、运行中阻断和逐条回执，不级联删除运行、事件、消息或凭据。
  - 工具连接、最近同步记录、自动化运行历史统一为「CAS + 软归档」删除合同；新装与迁移后默认恰好三条已启用规则（每日资讯、文献矩阵、文献综述）。
- **界面**
  - 文献检索、Obsidian、Zotero 使用统一可调分栏；可复用选择条（半选/全选/清除/二次确认）；外部链接只允许 `http:`/`https:`；Markdown H2 分节可折叠并带 `aria-expanded`/`aria-controls`；长路径与长内容滚动契约在 1440/1080/720/320 宽度下逐页断言。

## 尚未实现 / 未验收

- 安装包未签名，未接入自动更新（没有 `latest.yml`/publish provider）。
- 真实 Zotero 授权写入与远程删除 round-trip、真实用户 Obsidian Vault 与外部编辑冲突、cron 到点投递与启动补跑、带应用自有凭据的 Pi/Codex 模型输出，均未在本机真实环境验收。
- Notion 仍为手动同步 MVP：只做 GET-then-PATCH 的最佳努力推送，没有 durable outbox、幂等与三方冲突 UI，Core 拒绝 `both` 策略。
- 定时任务只在应用存活期间运行；启动最多补跑一次错过的每日任务。
