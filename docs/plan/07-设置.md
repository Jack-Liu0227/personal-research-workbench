## V2 打包配置规则

- Obsidian Vault 路径通过系统文件夹选择器取得，要求目录已存在；取消选择不清空旧值。Zotero Local API 地址和范围设置可直接在设置页保存。
- 配置写入工作区 SQLite；凭据仅在 Main 进程使用 `safeStorage` 保存。Renderer 只能通过 typed preload 调用，不能读取 Node、数据库、绝对路径或原始 token。
- 开发和打包环境都可用应用目录旁 `.env` 提供 `OBSIDIAN_DIR`、`ZOTERO_API_URL` 两个非敏感默认值；覆盖 `.env` 是受支持的默认配置入口，但修改后必须重启并重新真实探测。设置页保存的连接配置优先于 `.env`。
- 地址校验只接受 HTTPS 或 localhost/loopback；错误返回有限的安全摘要，不能泄露完整路径、正文或凭据。

## V2 当前非目标

本版本不执行 AI Provider、Agent、RAG、Automation/Cron、邮件投递或无人值守外部写入。相关设置项可以保留为后续设计，但必须显示“未启用/后续”，不能发送旧路由或假连接状态。

## Zotero/Obsidian 配置验收路径（新增需求）

1. 在“工具连接”中新建或编辑 Zotero profile，填写有效的 `http://localhost:23119/api/`（或 HTTPS）地址和 library JSON；URL 拼写错误时显示中文校验错误，不自动替换。
2. 点击保存后由本地主进程执行真实 probe；Zotero 未运行、未授权或 Better BibTeX 能力缺失时显示对应状态，不显示绿色假连接。
3. 关闭并重启应用，确认 profile、地址和非敏感范围仍存在；凭据仍只由 Main `safeStorage` 管理。
4. Obsidian 路径只通过“选择文件夹”取得；取消选择不清空旧值，保存后执行一次真实 Vault 探测。
5. 打包版可在安装目录旁覆盖 `.env` 的两个非敏感默认值；重启后必须在设置页确认实际连接状态。凭据仍必须通过设置页输入并由 Main `safeStorage` 保存。

## RSS 来源管理

设置页将“RSS 来源”作为与“工具连接”同级的一级分区。输入 URL 后先抓取并展示名称、网站和描述预览，确认后保存并选择分类。内置分类为技术新闻、学术论文、行业动态和 AI / 科技，也支持新增、重命名和删除自定义分类；内置分类不可修改，仍被来源使用的自定义分类不可删除。

每个来源分别控制“启用抓取”和“加入日报”。删除会硬删除来源配置并停止后续抓取，但已抓取文章保留来源名称、URL 和分类快照，可继续在情报库查询；再次添加同一 URL 会生成新的来源记录。

情报日报的来源筛选提供“全部来源”和每一个已配置 RSS 来源，筛选依据为来源 ID；来源分类用于归档和日报分组，不作为来源筛选项。

## 2026-08-30 需求增量：可配置运行环境与知识引擎

- 设置分为工作区与数据、文献源、Obsidian、Zotero、知识引擎、MCP Server、外观和环境检测；URL、端口、默认存储目录和 key 不得写死。

## 2026-08-30 打包路径与 `.env` 覆盖约定

- 打包版默认将 `data/`、`config/`、服务管道状态放在每用户 AppData `userData` 根目录；显式 `--prw-user-data-dir=<绝对路径>` 优先，用于多用户/测试隔离，且拒绝文件系统根目录。
- 安装目录旁的 `.env` 仅读取 `OBSIDIAN_DIR`、`ZOTERO_API_URL` 两个非敏感默认值；凭据仍只进入 Main 的 `safeStorage`。设置页保存的连接配置优先于默认值，修改 `.env` 后需重启应用并重新执行真实探测。
- `ZOTERO_API_URL` 必须是 `https://` 或 localhost/回环地址；例如 `http://localhost:23119/api/`，不会把 `http://1ocalhost...` 这类拼写错误伪装成已连接。

## 2026-08-30 最终基线：可移植默认值与环境设置

- 打包版默认把 SQLite、配置和同步状态放在每用户 AppData 的 `userData/data/`/`config/`；设置页可查看真实工作区状态，旧安装目录的数据在首次升级时迁移并保留源目录以便恢复。
- 相邻 `.env` 只覆盖 `OBSIDIAN_DIR` 与 `ZOTERO_API_URL` 两个非敏感默认值；设置页持久化配置优先，修改 `.env` 后显示“需重启并重新探测”。token/key 只存 Main `safeStorage`。
- 通用设置补齐主题、字号、紧凑度、语言、时区和减少动效；文献源逐项配置 URL/key/超时/分页；知识引擎与 MCP Server 提供启用开关、连接检测、scope、端口和复制给其他 Agent 的教程。未运行的服务显示未配置，不伪造在线。
