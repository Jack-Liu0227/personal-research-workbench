# 仪表盘

## 2026-09-08 最新需求与验收（以本节为准）

- `ARTIFACTS / RECENT` 与 `AGENT / INBOX` 只能来自 Workspace SQLite 的真实查询；空数据必须显示空状态，禁止演示行。
- 每条指标、Artifact、Agent run、Paper、Task 都必须是可点击入口，跳转到已有详情页并携带稳定实体 ID。
- 仪表盘卡片与详情页使用同一查询快照，数量和列表不得来自两套数据。
- 连接、运行失败、未配置状态必须原样显示，不得用成功占位。

## V2 当前边界与事实来源

- 仪表盘只通过 Workspace Service 读取统一 SQLite 快照；任务、日历、项目、Paper、检索会话、Obsidian 索引和连接状态不能在页面内各自维护副本。
- 任务归档、恢复和硬删除后的卡片、日历投影、项目计数与最近活动必须由同一组查询失效策略刷新；硬删除只有数据库事务提交后才能显示成功。
- 当前版本不执行 AI、Agent、RAG、自动化或无人值守外部写入。AnythingLLM/LLMWiki 等连接若未真实探测成功，只显示 `未配置`/`不可用`，不得用演示状态填充卡片。
- 外部 Agent/MCP 活动仅展示已记录的安全摘要；写操作仍回到对应业务服务，不由仪表盘直接批量写入。
- 仪表盘的任务入口统一跳转“我的任务”；不显示或重新引入 FOCUS 导航分组。

## 跨模块摘要契约

仪表盘卡片的最小输入来自同一时间快照：今日任务（含真实状态/优先级/截止时间）、日历显式事件与任务/项目只读投影、项目进度、当前检索结果统计、Paper/Obsidian 关联状态和后台运行记录。每张卡片必须带来源实体 ID，点击后打开现有标签或用户明确要求的新标签；不存在的实体不生成“成功打开”的假状态。

## 页面目标

汇总今天最需要处理的科研事项、项目进度、待读资源、后台任务和外部 Agent 活动，让用户进入应用后立即获得全局状态。

## 页面结构

### 顶部概览

- 日期、当前项目上下文和快捷创建。
- 今日完成、未完成、即将截止、待读文献、后台运行数量。

### 主内容卡片

- 今日任务：优先级、时间、项目、快速完成和延期。
- 即将截止：未来 7 天任务、里程碑、实验、投稿与返修节点。
- 最近项目：状态、进度、下一里程碑、任务和论文数量。
- 日历摘要：今日时间线与未来事件。
- 待读文献：标题、作者、年份、来源、状态和项目。
- 最近笔记：Obsidian 路径、标签、修改时间和关联资源。
- 后台任务：检索增强、索引、备份、AI Job、Wiki 摄取。
- 外部 Agent 活动：MCP 客户端、调用工具、资源范围和结果。
- 连接状态：Scholar、Zotero、Obsidian、AnythingLLM、LLMWiki、AI Runtime、MCP。

## 关键操作

- 点击卡片在全局标签页中打开资源。
- 支持卡片显隐、排序和尺寸预设。
- 从任务、论文或项目卡片派发 AI Job（后续阶段）；当前版本不发送 AI 执行请求。
- MCP 外部 Agent 创建或更新资源后，仪表盘实时刷新并标记变更来源。

## 后续设计：每日推送与收件箱（未启用）

以下内容是后续阶段设计；当前版本只展示已有数据库记录，不运行定时 Agent 或自动投递。

- “今日科研简报”显示生成 Agent、计划时间、数据截止时间、覆盖项目、来源数和投递状态。
- 默认模板汇总今日任务、日程、截止风险、保存检索新增论文、Zotero 新增和知识库变化。
- 支持立即运行、查看运行轨迹、标记已读、转为任务、固定到项目和重新投递。
- 简报内容保存为 `ai_artifact`，仪表盘只显示摘要；原始查询范围和引用在详情中查看。
- AnythingLLM 是最快接入的默认定时 Agent；AgentScope 用于多 Agent、渠道投递和更复杂的无人值守简报。

## MCP 范围（当前只读/受控）

- Resources：今日摘要、项目摘要、后台任务摘要。
- Tools：读取仪表盘摘要、获取异常状态、获取等待确认的 AI Job。
- 仪表盘本身不提供直接批量写入工具，写操作路由到对应业务服务。

## 2026-08-30 需求增量：跨模块一致性状态

- 仪表盘所有任务、日历、论文和知识引擎摘要均从统一 Workspace Service 查询；任务/日历变更后不保留页面私有旧数据。
- 顶部状态卡显示数据根目录、Zotero、Obsidian、AnythingLLM、LLMWiki 和 MCP 的真实配置/探测状态；禁止把未运行服务显示为已连接。
- 失败状态必须提供可执行的修复提示（URL、路径、端口、权限或重启），并链接到对应设置页。
