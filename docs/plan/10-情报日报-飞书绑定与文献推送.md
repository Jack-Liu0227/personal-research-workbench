# 情报日报与 RSS 文献推送

情报日报从工作台 SQLite RSS 数据读取文章，支持“全部来源”或单个 RSS 来源、关键词、作者和年份筛选。每日 `literature_daily_msg` 读取启用抓取的来源，抓取 RSS 1.0、RSS 2.0 或 Atom，按文章 URL 去重并将新增文章发送到已绑定的飞书机器人；流程不调用 Agent 或模型。

## RSS 来源管理

设置页支持 URL 元数据预览后保存来源，字段包括名称、RSS 地址、网站、描述、分类、抓取状态和日报展示状态。内置分类为技术新闻、学术论文、行业动态、AI / 科技；用户可新增、重命名和删除自定义分类，内置分类不可修改，仍被来源使用的分类不可删除。

删除来源会硬删除来源配置并停止抓取，已入库文章保留来源名称、URL 和分类快照，可继续查询和追溯；重新添加同一 URL 会创建新的来源记录。历史文章不会因来源删除而级联删除。

## 运行与验证

默认来源为掘金、Hacker News、Nature、npj Computational Materials、Nature Machine Intelligence。日报按分类和来源分组，最多 20 条，消息按飞书限制分块。专项检查使用 `pnpm test:rss-daily-msg`，跨层检查使用 `pnpm typecheck`、`pnpm build` 和 `pnpm test:e2e`；真实 RSS 网络抓取与真实飞书投递属于外部依赖，需单独验收。

设置页中的“RSS 来源”与“工具连接”同级。来源分类用于归档和日报分组，日报交互筛选固定显示“全部来源”及每个 RSS 来源，避免分类与来源列表不匹配。
